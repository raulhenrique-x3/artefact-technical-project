# Task Manager

## Objetivo
Desenvolver uma aplicação web simples para gerenciamento
de tarefas utilizando Next.js 15 e tRPC.

## Funcionalidades
- Listar tarefas
- Criar tarefas
- Editar tarefas
- Excluir tarefas

## Requisitos funcionais
- Toda tarefa deve possuir um ID único.
- O título é obrigatório.
- A descrição é opcional.
- A data de criação deve ser gerada automaticamente.
- A listagem deve ser renderizada inicialmente no servidor.
- O usuário deve receber feedback após as operações.

## Restrições
- Não utilizar banco de dados.
- Os dados devem ser mantidos em memória.
- Utilizar tRPC para comunicação com o backend.
