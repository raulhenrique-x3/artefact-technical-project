# Acceptance Criteria

## Create Task
- O usuário consegue criar uma tarefa.
- O título não pode estar vazio.
- A descrição é opcional.
- A tarefa aparece na listagem após a criação.

## Update Task
- O usuário consegue editar uma tarefa existente.
- O sistema retorna um erro se a tarefa não existir.

## Delete Task
- O usuário consegue excluir uma tarefa.
- A tarefa removida deixa de aparecer na listagem.

## List Tasks
- A listagem é pré-carregada utilizando SSR.
- O usuário recebe feedback durante o carregamento.
